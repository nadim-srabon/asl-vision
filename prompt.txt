# Project: ASL Vision – Interactive Hand Sign Recognition Web Application

## 1. Your Role

Act as a Senior Machine Learning Engineer and Python Web Application Developer.

I have completed a university capstone project with my team. We trained a video-based American Sign Language (ASL) hand sign recognition system using the R3D_18 3D Convolutional Neural Network architecture.

We trained four different model configurations:

- 300
- 500
- 1000
- 1200

Your task is to build a complete, attractive, interactive web application that showcases our research, allows visitors to test our trained models, and compares their performance.

This application will be demonstrated during our university capstone presentation.

Requirements:

- Use the exact trained architecture.
- Load the correct class mapping.
- Use model.eval().
- Use torch.inference_mode().
- Support CPU inference.
- Do not require CUDA.
- Validate checkpoint compatibility.
- Validate output dimensions.
- Handle state dictionaries correctly.

### MEMORY OPTIMIZATION

Streamlit Community Cloud has limited resources.

Therefore:

- Never load all four models simultaneously.
- Load only the currently selected model.
- Cache model loading appropriately using st.cache_resource.
- Avoid unnecessary model copies.
- Release previous model resources when changing configurations.
- Avoid loading training datasets into memory.
- Avoid unnecessary dependencies.
- Keep the inference pipeline memory-efficient.

Do not retrain or modify existing model weights.

Do not replace our trained checkpoints with pretrained ImageNet weights.
